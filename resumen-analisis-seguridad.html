🌐 SECCIÓN 5: Escaneo Dinámico DAST (OWASP ZAP · reporte-zap.html)

Hallazgos generados atacando la aplicación corriendo en tiempo de ejecución en http://localhost:3000.

🟠 Alertas Medias (Medium) — Prioritarias

1. Content Security Policy (CSP) Header Not Set

Qué significa: La aplicación no define la cabecera Content-Security-Policy. Esto permite que si alguien inyecta código malicioso (XSS), el navegador lo ejecute sin restricciones de origen.

Corrección: Configurar la cabecera CSP en los middlewares de Next.js o Express (helmet).

Medium CWE-693 (Protection Mechanism Failure) OWASP A05:2021 - Security Misconfiguration

2. Missing Anti-clickjacking Header (X-Frame-Options)

Qué significa: No se incluye la cabecera X-Frame-Options: DENY o SAMEORIGIN. Un atacante puede incrustar el CRM dentro de un <iframe> en un sitio malicioso para engañar al usuario y hacer que haga clic sin darse cuenta (Clickjacking).

Corrección: Agregar X-Frame-Options: SAMEORIGIN en las respuestas HTTP.

Medium CWE-1021 OWASP A05:2021 - Security Misconfiguration

🟡 Alertas Bajas (Low) — Higiene y Cabeceras de Seguridad

  • X-Content-Type-Options Header Missing: Falta X-Content-Type-Options: nosniff para evitar que el navegador adivine el tipo MIME de archivos ejecutables.
  • Server Leaks Information via "X-Powered-By": La cabecera revela que el servidor corre sobre Next.js o Express. Se debe ocultar (poweredByHeader: false en next.config.js y app.disable('x-powered-by') en Express).
  • Cross-Origin-Opener-Policy (COOP) / COEP / CORP: Cabeceras de aislamiento entre orígenes ausentes.
  • Permissions Policy Header Not Set: No restringe el acceso de la aplicación a APIs del navegador como cámara, micrófono o geolocalización.
